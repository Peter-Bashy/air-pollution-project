# 🌫️ Air Pollution Analysis Using Hadoop Ecosystem

A Big Data project analyzing air pollution across 26 Indian cities (2015-2020) using the complete Hadoop ecosystem.

## 🛠️ Technology Stack
- **HDFS** — Distributed data storage
- **Apache Pig** — Data cleaning and transformation
- **MapReduce** — Record counting per city
- **Apache Spark** — Big data analytics
- **R** — Data visualization

## 📁 Project Structure

## 📊 Dataset
- **Source:** Kaggle — Air Quality Data in India
- **Records:** 29,531 rows
- **Cities:** 26 Indian cities
- **Period:** 2015–2020
- **Columns:** City, Date, PM2.5, PM10, NO, NO2, NOx, NH3, CO, SO2, O3, Benzene, Toluene, Xylene, AQI, AQI_Bucket

## 🔍 Key Findings
- 🏙️ **Ahmedabad** is most polluted (Avg AQI: 452)
- 🌿 **Aizawl** is cleanest (Avg AQI: 35)
- 📉 AQI decreased 46% from 2015 to 2020
- 🌧️ Monsoon months (Jun-Sep) have lowest pollution
- ❄️ Winter months (Nov-Jan) have highest pollution
- 🔬 CO and PM2.5 are strongest AQI drivers
